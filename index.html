    Abandoned but not Forgotten

    On the Moon there is no wind and no rain, so what we leave there can last for a very long time. Some of it still works: the laser mirrors of Apollo 11, Apollo 15, Lunokhod 1 and Chandrayaan-3 still help scientists measure the Moon today.

        Transparency

        How this was made · Super Intelligence (SI / AI) use disclosure

        AI-assisted

        • Source code (Vite, Three.js, Leaflet, satellite.js) was written with an AI coding assistant and reviewed and tested by the team.
        • Draft text (story cards, event descriptions, prompts) was written with AI assistance, then checked line by line against the linked NASA and peer-reviewed sources.
        • Procedural 3D reconstructions (marked “procedural”) were coded, not generated by an image model.
        • Pip, the guide, is a hand-drawn SVG/CSS character; his scripted lines were written with AI help and checked by the team.
        • Ask Pip chat: when you type a question to Pip, the answer is generated live by a large language model (an open Gemma / Nemotron model or Google Gemini, reached through OpenRouter) via our own server proxy (a Supabase Edge Function). Answers are AI-generated, not checked by the team, and can be wrong — always check the linked NASA sources. We send only your question and the last few chat lines; nothing is stored. If the AI is unavailable, Pip answers from a small built-in fact list instead.

        Not AI-generated

        • No AI-generated images, video, voices or music. Sound effects are synthesised beeps in the browser.
        • All photographs, map tiles and “NASA model” 3D files are NASA (and partner) public-domain media, credited where shown.
        • No NASA logos, insignia or mission patches are used in any media we made.

        Limits

        • Gauge values and scores are a game model.
        • Map markers mark landing or descent-stage positions from published tables; rovers may have moved from these points.
        • Not affiliated with or endorsed by NASA.

        Fact or game?

        Real: every event, date, decision, outcome, coordinate and photo, with a linked NASA or peer-reviewed source. Game model: the gauge numbers (battery, temperature, dust, integrity) and the score.

        Accessibility

        Fully keyboard-playable (number keys pick choices, Tab moves through everything). Each 3D view has a text description; every map pin is also a list button; screen readers hear each event and outcome. Motion is reduced when the system “reduce motion” setting is on. Sound is optional. Pip can be dragged anywhere (double-tap to send him home) and his chat works with the keyboard.
