Простой старт

Редактируй файлы в папке src. Vite обновит страницу автоматически, а готовую сборку можно будет развернуть на хостинге.

Команды

  • npm run dev — запустить режим разработки
  • npm run build — собрать сайт для публикации
  • npm run preview — проверить готовую сборку
